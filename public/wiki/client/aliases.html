Aliases

Client-side command shortcuts — not Powermud’s in-game alias command.

Commands

InputAction
/alias NAME EXPANSIONCreate or replace an alias
/unalias NAMERemove an alias
/aliasesList all aliases
/aliases filterList aliases whose name or body matches filter

Names are one word, case-insensitive. Expansions can be several MUD commands.

Expansion features

  • Chains — separate commands with ; (e.g. look;score).
  • Trailing args — a one-word alias can take the rest of the line (/alias bs backstab → bs orc sends backstab orc).
  • Prefix args — name the alias NAME $1$ and use $1$ in the body for the words after the command (e.g. /alias ca $1$ cast stoneskin on $1$).
  • Nesting — aliases can call other aliases; cycles return an error instead of looping.
  • zScript — bodies containing # run a small Mudlet-style subset (limited timing and action lines).

Special “smart alias” marker strings from other clients are not supported here — those expansions are blocked for safety.

Autocomplete

Type / in the command field to suggest client slash commands and your alias names. While typing /alias … or /unalias …, alias autocomplete hides so you are not interrupted.

Hotkeys

InputAction
/hotkey "KEY" "COMMAND"Bind a key chord to send a command (alias-expanded, echoed like typing it)
/unhotkey NUMBERRemove a binding by list number
/hotkeyList hotkeys (numbered; same order as /unhotkey)

Use F1–F12 or a chord with Ctrl, Alt, Shift, or Meta (plain letters are not allowed — they would conflict with typing). Alt+W/M/C/D stay reserved for built-in panel shortcuts. Stored in localStorage as playpowermud-hotkey.

When commands

InputAction
/when "TRIGGER" "COMMAND"Auto-send a command when MUD output contains the trigger text
/unwhen NUMBERRemove a rule by list number
/whenList when rules (numbered)

Stored in localStorage as playpowermud-when.

Storage

Aliases live in this browser’s localStorage under playpowermud-aliases. They do not sync across devices or browsers. Use Export config / Import config on the play page to back up aliases, comms, skin, and your learned map. Powermud’s own saved aliases (if any) are separate — use this client’s /alias for playpowermud.

Examples

/alias cma cast magic invulnerability
/alias bs backstab
/alias ca $1$ cast stoneskin on $1$;cast bless on $1$
/alias esetcolors eset ansi on;eset tell bold blue;eset say green

Then type ca bishop or esetcolors like ordinary commands (no leading /).
