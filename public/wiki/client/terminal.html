Terminal & colors

xterm.js output with full ANSI — Powermud eset colors render as the MUD sends them.

Command line

  • History — ↑ and ↓ walk previous commands (plain arrows, not modified).
  • Repeat — Enter on an empty line resends the last command.
  • Password — input is masked while Powermud asks for your password.
  • Line cursor — ←/→ move within the line; Alt+←/→ insert telnet cursor-move sequences at the caret.
  • Log cursor — Alt+Shift+arrow sends cursor keys to the MUD (for full-screen editors on the game side).
  • Word delete — Alt+Backspace deletes the word before the caret (macOS Option+Backspace).
  • Back to terminal — Alt+D scrolls the log to the bottom and focuses input (shortcut list).

Mobile

On small screens, quick buttons for look, who, and score appear above the input; Map and Comms toggle the side panels.

Theme

Skin: Dark / Light on the play page (and this wiki) switches UI chrome only; MUD colors still come from ANSI. The choice is saved in localStorage.

Powermud ANSI (eset)

In-game: help ansi, help eset, help variables. Help digest: Eset & ANSI.

  • eset ansi on — required for channel colors and combat ANSI.
  • eset <variable> <setting> — e.g. eset tell bold blue.
  • eunset <variable> — clear one variable.

Colors: black, red, green, yellow, blue, purple, cyan, white.

Effects: beep, flash, underline, normal, bold, italics, inverse (not every effect shows in every client).

Suggested channel preset

Define once as a client alias (see Aliases), then run it each session:

eset ansi on
eset tell bold blue
eset say green
eset shout bold cyan
eset announce bold yellow
eset guild bold purple
eset groupchat bold magenta
eset fields green
eset emote cyan

Example client alias: /alias esetcolors eset ansi on;eset tell bold blue;eset say green;… — run esetcolors after each login, then verify with eset.
