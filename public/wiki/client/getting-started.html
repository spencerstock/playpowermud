Getting started

Connect from the home page and play. The client talks straight to Powermud.

What this client is

Play Powermud is a browser client for Powermud: a terminal, personal aliases, a comms log, and a world map in one tab. The page opens a WebSocket to the game. Aliases and comms preferences use localStorage, and map discoveries use IndexedDB on this device.

Keyboard shortcuts

On macOS, Alt is labeled Option. Shortcuts use Alt, not Option+Command.

ShortcutAction
Alt+WToggle wiki overlay
Alt+MToggle world map panel
Alt+CToggle comms panel
Alt+DFocus terminal: scroll log to bottom and focus the command line

Custom key bindings: header Menu → Hotkeys…, or /hotkey in the command line.

Connect

  1. Open / and click Connect.
  2. Log in on Powermud as usual (name, password). The password field is masked in the UI.
  3. Use the command line at the bottom; ↑/↓ recall history. Empty Enter repeats the last command.

Connect opens wss://powermud.com:2000 — Powermud production. Port 2001 is their dev game, not this client. A dropped socket shows as disconnected from Powermud; click Reconnect (or press Enter) to log in again. Session length is the game and your network, not a timer on this site.

?relay=wss://… on the page URL overrides that socket (support and local testing). A self-hosted TCP bridge (yarn relay) is only for a MUD that has no WebSocket. Build that client with MUD_WS_URL=wss://your-host/api/ws. RELAY_URL is the old name for the same build setting.

Wiki while you play

Click Wiki in the header (or press Alt+W) to open help and game reference in an overlay on top of the client. Your MUD connection stays open underneath — close the wiki or press Escape to return to the terminal (new output appears when you close; text you missed while reading is not replayed).

Run locally

yarn install
yarn dev    # http://localhost:3000 — client still uses wss://powermud.com:2000

The dev server also keeps a local pipe at ws://localhost:3000/api/ws. Use it with ?relay=ws://localhost:3000/api/ws. Run yarn build before deploy; Vercel serves public/.

What is not in this client

Play Powermud is intentionally simple: no auto-walking, speedwalk, click-to-walk on the map, trigger scripts, imported “smart” alias packs, or saved login profiles. You send each command yourself from the command line.
