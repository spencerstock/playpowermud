Getting started

Connect from the home page, play in one tab, reconnect when the relay drops.

What this client is

Play Powermud is a browser client for Powermud: a terminal, personal aliases, a comms log, and a world map in one tab. Everything except the network relay runs in your browser; aliases and comms preferences use localStorage, and map discoveries use IndexedDB on this device.

Keyboard shortcuts

On macOS, Alt is labeled Option. Shortcuts use Alt, not Option+Command.

ShortcutAction
Alt+MToggle world map panel
Alt+CToggle comms panel
Alt+DFocus terminal: scroll log to bottom and focus the command line

Connect

  1. Open / and click Connect.
  2. Log in on Powermud as usual (name, password). The password field is masked in the UI.
  3. Use the command line at the bottom; ↑/↓ recall history. Empty Enter repeats the last command.

The site talks to Powermud through a relay at /api/ws — a dumb pipe to powermud.com:2000. You cannot point the public relay at another host from the browser; only the server config chooses the target.

Session length (Vercel)

On Vercel, the WebSocket closes when the function hits its max duration (about 5 minutes on Hobby, longer on Pro). When the relay drops, your character goes link-dead and you will see the login prompt again after reconnect.

For long uninterrupted sessions, run your own relay:

yarn relay   # standalone relay; set PORT, MUD_HOST, MUD_PORT

Build or load the client with RELAY_URL=wss://your-host/api/ws, or add ?relay=wss://… to the page URL for a quick test.

Run locally

yarn install
yarn dev    # http://localhost:3000 — static site + relay at /api/ws

Run yarn build before deploy; Vercel serves public/ and deploys the relay function.

What is not in this client

Play Powermud is intentionally simple: no auto-walking, speedwalk, click-to-walk on the map, trigger scripts, imported “smart” alias packs, or saved login profiles. You send each command yourself from the command line.
