Skill trainers

Standalone skills (riding, tailoring, forging, first aid, and similar) are not the same as professions or guild combat training. Skill NPCs usually say they have “skills to teach you” when you list. Use learn <skill> when you have enough gold and meet any ability checks. See also Profession trainers for Doctor, Brawler, and other profession paths.

This page records skill-trainer locations as players map them. Costs and currency match what the NPC shows in list (often much lower than profession fees).

Crossroads

Saret Johay in Crossroads (speaks Drow) teaches the following (from in-game list):

Skill Cost to learn Abilities required
Riding 420 None

Useful for travel and for guilds that use mounted combat (for example Knights of Nereka and Rangers).

The Wandering Tailorer (speaks Drow; found around Crossroads) teaches the following (from in-game list):

Skill Cost to learn Abilities required
Tailoring 1,200 None

Dunkrist

Hardiys Hojlen in Dunkrist (speaks Drow) teaches craft skills. From in-game list:

Skill Cost to learn Abilities required
Forging 1,440 None
Mining 1,200 None

The teacher in Dunkrist teaches the following (from in-game list):

Skill Cost to learn Abilities required
Teaching 12 None

The Natural Healer in Dunkrist (speaks Drow) teaches the following (from in-game list):

Skill Cost to learn Abilities required
First aid 1,380 None
Harvesting 600 None

These pair with the Doctor path; the Herbalist profession in Dunagin is the usual next step toward Doctor.
