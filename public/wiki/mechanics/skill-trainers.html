Skill trainers

Standalone skills (riding, tailoring, forging, first aid, and similar) are not the same as professions or guild combat training. Skill NPCs usually say they have “skills to teach you” when you list. Use learn <skill> when you have enough gold and meet any ability checks. See also Profession trainers for Doctor, Brawler, and other profession paths, and Languages for tongue teachers.

This page records skill-trainer locations as players map them. Costs and currency match what the NPC shows in list (often much lower than profession fees).

Crossroads

Saret Johay in Crossroads teaches the following (from in-game list):

Skill Cost to learn Abilities required
Riding 420 None

Useful for travel and for guilds that use mounted combat (for example Knights of Nereka and Rangers).

Kalinport

Skill teachers recorded in the Merchant's Diamond (and nearby Kalinport shops).

The Riding Instructor teaches the following (from in-game list):

Skill Cost to learn Abilities required
Riding 840 None

Riding costs vary by town (420 at Crossroads, 720 in Deepwater, 840 here). Useful for travel and for guilds that use mounted combat (for example Knights of Nereka and Rangers).

An Instructor in the Diamond teaches potion-related skills (from in-game list):

Skill Cost to learn Abilities required
Brewing 12,000 None
Concocting 15,000 None

These pair with the Merchant's Guild (brewing potions, alchemy, and concoctions) and the Alchemist profession in Kalinport's Professions Annex.

Nal Shaddar

The Loreman in the Lore Room of Melee-Magthere teaches advanced combat and utility skills (from in-game list in session logs and mapped rooms). These are separate from the guild cost / train table in the same room.

Skill Cost to learn Abilities required
Advanced unarmed 3,500 None
Asperser 7,500 None
Disarm 3,000 None
Dual 4,000 Strength 14 and Dexterity 16
Epic pierce 50,000 None
Epic slash 45,000 None
Pierce aversion 5,000 None
Ranged 4,000 None
Riding 4,500 None
Slash aversion 5,000 None
Swim 3,000 None
Unarmed dual 5,000 None

Your list may omit skills you have already learned. Riding here costs more than in most surface towns (for example 420 at Crossroads or 840 in Kalinport).

Rothe Island

A Fisherman on the Rothe Island dock (subterranean lake south of Nal Shaddar) teaches fishing (from in-game list in mudwithme session logs).

Skill Cost to learn Abilities required
Fishing 1,320 None

Long fishing poles and hooks on corpses are tied to fishermen in several ports (Cerene, Threshold docks, and elsewhere); this NPC is the list source recorded for the island dock.
