PK areas

From in-game help pkareas (2026-10-19).

Command

pkareas — lists areas where player killing is allowed. The list can vary by reboot.

A 2026 help pull listed Threshold and Threshold Graveyard; the live set can differ after reboot. Always run pkareas before assuming an area is safe.
